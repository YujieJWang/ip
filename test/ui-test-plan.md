# UI Test Plan

## Compilation

```bash
javac src/main/java/*.java -d out/production/ip
```

## Test Cases

### Test: Greet and exit

**Aim:** Verify the app shows a greeting banner and exits cleanly on `bye`.

**Inputs:**
```
bye
```

**Expected output:**
```
    ____________________________________________________________
     _       _                       
    | | ___ | |__  _ __  _ __  _   _ 
 _  | |/ _ \| '_ \| '_ \| '_ \| | | |
| |_| | (_) | | | | | | | | | | |_| |
 \___/ \___/|_| |_|_| |_|_| |_|\__, |
                                |___/ 
     Hello! I'm Johnny.
     What can I do for you?
    ____________________________________________________________
    ____________________________________________________________
     Bye bye! See you again soon.
    ____________________________________________________________
```

**Inputs:**

**Expected output:**

```
     What can I do for you?
```
